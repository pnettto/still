# Nature recordings

Real field recordings from Wikimedia Commons. Each was trimmed, loudness-normalised (−24 LUFS) and encoded as MP3, then embedded as base64 in a small script so the app also works from `file://`. The app folds the end of each clip over its beginning, so it loops without a seam.
